# Tank Duel

A polished 2-player top-down tank battle game.

## Controls

### Player 1
- **Move**: WASD
- **Shoot**: SPACE

### Player 2
- **Move**: Arrow Keys
- **Shoot**: ENTER

## Features
- **Modular Engine**: Clean separation of physics, input, and rendering.
- **Power-ups**: Speed Boost, Shield, Rapid Fire.
- **Procedural Audio**: Built-in sound synthesis.
- **High-Performance**: Particle systems and optimized collision.

## Tech Stack
- HTML5 Canvas
- Vanilla JavaScript (ES6 Modules)
- Web Audio API
